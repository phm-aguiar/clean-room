# Text Formatting

## Emphasis

```markdown
**Bold text**
__Also bold__ (double underscore)

*Italic text*
_Also italic_ (single underscore)

***Bold and italic***
___Also bold and italic___

~~Strikethrough~~
```

## Inline Code

Use backticks for inline code:

```markdown
`inline code`
```

For code with backticks inside, use multiple backticks:

```markdown
`` `code with backticks` ``
```

## Blockquotes

```markdown
> Single line blockquote

> Multiple lines
> in a blockquote
> look like this

> **Note:** You can use markdown inside blockquotes
> - Bullet points work
> - _Emphasis_ works
```

## Horizontal Rules

Any of these create a horizontal rule:

```markdown
---
***
___
```

## Line Breaks

Two spaces at end of line creates a line break (soft break):

```markdown
This line ends with two spaces  
And this is the next line
```

Or use a blank line for a paragraph break (hard break):

```markdown
This is a paragraph.

This is a new paragraph.
```
