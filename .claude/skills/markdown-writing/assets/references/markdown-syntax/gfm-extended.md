# GitHub Flavored Markdown Extensions

## Strikethrough

Use double tildes around text:

```markdown
~~This text is struck through~~

The ~~old~~ new way to do this.
```

## Task Lists

Create checklists with square brackets:

```markdown
- [x] Completed task
- [ ] Incomplete task
- [x] Another completed task
- [ ] Task with `code`
- [ ] Task with [link](https://example.com)
```

Checked items show with `[x]`, unchecked with `[ ]`.

## Autolinks

URLs and emails are automatically converted to links:

```markdown
Visit https://github.com for more info.
Email: support@example.com
```

## Mentioning Users and Teams

```markdown
@username mentions a specific user
@organization/team-name mentions a team
```

(Works on GitHub, GitLab, and similar platforms)

## Issue and PR References

Reference issues and pull requests:

```markdown
Fixes #123
Closes #456
Related to #789
```

(Contextual on GitHub; becomes plain text elsewhere)

## Table of Contents (via HTML comment)

```markdown
<!-- Table of Contents generated by tool -->
- [Section 1](#section-1)
- [Section 2](#section-2)
```

## Emoji (via GitHub emoji shortcodes)

```markdown
:+1: (thumbs up)
:bug: (bug icon)
:tada: (confetti)
```

See [GitHub emoji list](https://github.com/ikatyang/emoji-cheat-sheet) for all codes.

## Syntax Highlighting in Diffs

Specify language in triple backticks for code blocks:

````markdown
```diff
- old line
+ new line
  unchanged line
```
````

## HTML Passthrough

GitHub allows some HTML:

```markdown
<details>
<summary>Click to expand</summary>

Content here (needs blank line after `<summary>` for markdown to render)

</details>
```

## Footnotes

```markdown
Here is a footnote[^1].

[^1]: This is the footnote content.
```

(Support varies by platform)
